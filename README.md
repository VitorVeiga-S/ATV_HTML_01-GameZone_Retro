#  GameZone Retro - Página Promocional HTML

Este repositório contém o código-fonte de uma página promocional para a **GameZone Retro**, uma loja especializada em jogos e consoles clássicos. O projeto foi desenvolvido com o objetivo de demonstrar os conceitos fundamentais de estruturação e semântica em HTML.

---

##  Sobre o Projeto

A proposta do projeto é apresentar as informações da loja de forma direta, funcional e organizada, priorizando a clareza da estrutura do documento.

###  Recursos e Elementos Utilizados

* **Estrutura semântica:** Organização clara do conteúdo utilizando títulos, parágrafos e seleções de texto em negrito e itálico.
* **Navegação interna e externa:** Links funcionais para navegação até a seção de preços (âncora) e direcionamento para redes sociais.
* **Lista de produtos:** Apresentação dos consoles disponíveis em formato de lista.
* **Tabela de preços:** Exibição clara dos principais jogos, plataformas compatíveis e seus respectivos valores.
* **Mídia:** Inclusão de elemento de imagem relacionado ao tema retrô.
